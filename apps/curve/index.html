pedersen commitments

two streams of field elements + two blindings → three commitments. the protocol's element-wise additive-homomorphism contract: C(a, r_a) + C(b, r_b) ≡ C(a + b, r_a + r_b) where a + b is the element-wise sum. each stream position has its own pinned generator G_i, so a future ZK predicate can prove "the i-th element is X" without touching the others. enter streams as comma-separated decimals.

schnorr signatures

sign a field-element message with a randomized seed. the signature is (R, s); the panel plots PK and R and verifies s·G == R + c·PK in-page. the tamper button adds 1 to s mod l to demo the rejection path — when tampered, the verification line turns red and the connecting stroke follows.

text-utf8-v1 encoding

type text → see the 9-element field stream → round-trip back to bytes. f_0 is the length prefix in bytes (shown as a bar against the 248-byte max); f_1..f_8 are 31-byte chunks (bright when non-zero, dim when zero-padded). the symmetry line confirms decode(encode(bytes)) ≡ bytes — the load-bearing round-trip invariant pinned in specs/encodings/text-utf8-v1.md.
